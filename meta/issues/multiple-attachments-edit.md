# Edit: remove files from a message

Parent: [Several files in one message](multiple-attachments.md)

## Summary

As in Discord: while editing, each file of the message has a remove
button; files cannot be added. Removing the last file of a message
without text deletes the message (Discord asks first).

## Acceptance Criteria

- Removed files are gone for all clients and their files are deleted.
- Only the author can remove files (moderators delete whole messages).
