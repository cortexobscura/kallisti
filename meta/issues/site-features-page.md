# Website and README: show what Kallisti does now

## Summary

The website (site/, published 2026-10-18) and the README describe Kallisti as it was then. Since then about 250 feature commits came in: Go Live with camera or screen and several streams at once, streams from OBS (WHIP), music mode, recording, threads and categories, invite-only channels, fediverse login, personal emoji, many moderation tools, Web Push and the PWA, native notifications in the desktop app, more deploy variants. The landing page stays short; a new features page lists everything; the README becomes a shorter, technical overview that links to it.
