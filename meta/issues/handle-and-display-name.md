# A fixed handle and a display name

## Summary

Accounts have one name: it identifies them (mentions, Mumble, logins)
and it is what others see. Discord and the fediverse keep a fixed handle
apart from a display name that is free to change. Both reviewers of the
fediverse-name question (2026-11-01) called this the right long-term
model, not needed for add-server-via-fediverse.md.

## Requirements

- To be designed: the handle (unique, as now) and a display name per
  account; where each shows (chat, member list, Mumble, mentions);
  renames; the existing accounts.

## Acceptance Criteria

- A design the user agrees to, then sub-issues.
