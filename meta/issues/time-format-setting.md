# Setting: 24-hour time

## Summary

Message times follow the browser's language (12-hour for English). Users
want 24-hour time.

## Requirements

- A setting "Time format": automatic (as now), 12-hour, 24-hour; saved.
- Used for all message times (and "Today at …").

## Acceptance Criteria

- With 24-hour, an English browser shows "Today at 19:05".
- Tests for the formatting.
